# CommandLine
CommandLine.txt is a simple text file containing notes taken from a Udemy course presented by Colt Steele. The course covers git and git hub. 

The file is live and grows as lessons in the course dive into syntax of git bash commands. It is a chronicle of my official journey of using git and github. It is a preliminary step in learning more about using Docker with Ignition 8.3 for my professional as well as personal interests using Ignition Maker edition with Arduino and Raspberry Pi. 

Future repositories will contain development of my model railway, "Starlythe Park Rail Way". My intention is to utilize these repositories in connection with YouTube and just to have some fun building and sharing.
